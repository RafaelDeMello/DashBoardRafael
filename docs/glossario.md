# Glossário

Termos técnicos explicados em linguagem simples. Cresce junto com o projeto.

- **MVP** (Minimum Viable Product): versão mínima do produto que já é útil de verdade.
- **Regra de negócio**: afirmação sobre como o "mundo" do app funciona, independente de código.
  Ex.: "tarefa não feita pode ser movida para outro dia".
- **Servidor**: computador na internet que guarda os dados e os entrega a quem tem permissão.
- **Login (autenticação)**: provar quem você é (e-mail e senha).
- **PWA**: site que pode ser instalado no celular e se comporta quase como um aplicativo.
- **Modelo de dia**: estrutura de lista reutilizável (seções e itens) usada para criar a lista de cada dia.
- **Progresso**: itens marcados como feitos dividido pelo total, em porcentagem.
- **Recorrência**: algo que se repete automaticamente (ex.: toda segunda-feira).
- **ADR** (Architecture Decision Record): arquivo curto que registra uma decisão técnica:
  problema, opções, decisão e motivo.
